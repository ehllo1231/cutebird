# 달을 꿈꾸는 새 · Moonbird Studio

아기 새의 드래그 점프를 시험하는 게임과 전용 맵 제작 도구입니다. **Unity 6000.4.5f1 / Windows 64비트 / 마우스·키보드**를 기준으로 제작했습니다.

## 실행

- 최신 앱 **v0.5.0**: `Builds/Windows-Developer/MoonbirdStudio.exe`를 실행합니다. 같은 폴더의 `MoonbirdStudio_Data`, `UnityPlayer.dll`, `MonoBleedingEdge` 등 동봉 파일도 필요합니다. 실행 파일만 옮기지 마세요. 기존 앱이 실행 중이면 맵을 저장하고 종료한 뒤 새 앱을 여세요. 화면 왼쪽 위에서 버전을 확인할 수 있습니다.
- 프로젝트 수정: Unity Hub에서 이 폴더를 추가해 Unity 6000.4.5f1로 엽니다. `Assets/Moonbird/Scenes/Studio.unity`를 열고 Play를 누릅니다.
- 다시 빌드: Unity 메뉴에서 **Moonbird → Build Windows App**을 선택합니다. 씬을 다시 준비하려면 **Moonbird → Prepare Studio Scene**을 사용합니다.

## 첫 플레이

앱을 열면 기본 코스가 나옵니다. **처음부터 테스트**를 누르고, 새가 바닥에 착지한 뒤 화면 아무 곳에서 마우스 왼쪽 버튼을 누르세요. 아래로 당겼다가 놓으면 반대 방향으로 점프합니다. 왼쪽 아래로 당기면 오른쪽 위로 날아갑니다.

당긴 거리로 힘이 정해지며 누른 시간은 영향을 주지 않습니다. 누른 지점에는 연노란 원이 생기고, 현재 마우스 위치까지 은은한 민트색 선분이 이어집니다. 이 선으로 당긴 방향과 거리를 확인할 수 있습니다. 기준점은 화면에 고정되고 선 끝만 마우스를 따라갑니다. 마우스를 놓거나 오른쪽 클릭·창 전환·재시작으로 점프를 취소하면 바로 사라집니다. 공중과 편집 화면에서는 표시하지 않습니다.

일반 플레이에서는 강도 수치·게이지·발사 화살표·예상 궤적을 표시하지 않습니다. 최대 힘을 넘겨도 속도는 더 커지지 않습니다. 공중에서는 조작할 수 없고, 착지한 뒤 다시 점프합니다.

발판은 모든 면이 단단합니다. 아래로 떨어져도 아래쪽 발판에 착지할 수 있으며, 낙하 한계 아래로 빠지면 테스트 시작점으로 돌아갑니다. 달에 닿으면 도착 화면이 표시됩니다.

| 조작 | 기능 |
| --- | --- |
| 아래로 드래그 후 놓기 | 점프 |
| R | 현재 테스트 시작점으로 돌아가기 |
| Esc | 편집 화면으로 돌아가기 |

## 맵 만들기

- **선택 · V** 모드에서 **+ 발판**으로 화면 중앙에 발판을 추가합니다. 발판을 드래그해 이동하고 모서리를 드래그해 크기를 바꿉니다. 오른쪽 패널에서 정확한 위치·크기도 입력할 수 있습니다.
- 작업 화면 위쪽의 **화면 드래그 · H**를 선택하면 왼쪽 버튼으로 화면을 끌어 이동합니다. 발판 위에서 끌어도 발판은 움직이지 않습니다. **선택 · V**로 돌아오면 발판을 다시 편집합니다.
- **Space + 왼쪽 버튼** 또는 **가운데 버튼 드래그**로 선택 모드를 유지한 채 잠깐 화면을 옮길 수 있습니다.
- 아기 새의 시작점과 달도 클릭하고 드래그해 이동합니다.
- 선택한 발판을 **복제**하거나 **삭제**할 수 있습니다. 마지막 발판은 삭제하지 않습니다.
- **맞춤**을 켜면 드래그 위치를 0.5 단위 격자에 맞춥니다. 숫자 입력은 입력한 값을 그대로 사용합니다.
- 높은 구간은 **선택 발판 테스트**로 바로 시험합니다. 편집으로 돌아오면 배치·설정·확대 상태가 유지됩니다.
- 오른쪽 패널은 스크롤할 수 있습니다. 아래쪽에서 낙하 한계와 격자 옵션을 조절합니다.

| 조작 | 기능 |
| --- | --- |
| V / H | 선택 모드 / 화면 드래그 모드 |
| Space + 왼쪽 버튼 / 가운데 버튼 드래그 | 임시 작업 화면 이동 |
| 마우스 휠 | 커서 주변을 한 칸마다 1.35배 확대·축소 |
| 작업 화면 위쪽 − / + | 화면 중심을 한 단계 축소 / 확대 |
| F / Home | 선택한 물체 보기 / 맵 전체 보기 |
| Ctrl+D / Delete | 선택 발판 복제 / 삭제 |
| Ctrl+Z / Ctrl+Y 또는 Ctrl+Shift+Z | 실행 취소 / 다시 실행 |
| Ctrl+S / Ctrl+Shift+S | 저장 / 다른 이름으로 저장 |
| Ctrl+O / Ctrl+N | 열기 / 새 기본 코스 |

## 점프 설정

| 항목 | 기본값 | 범위 / 의미 |
| --- | --- | --- |
| 점프 감도 | 1 | 0.1~3. 같은 당김으로 얼마나 빨리 최대 힘에 도달하는지 |
| 최대 발사 속도 | 18 | 5~40 월드 단위/초 |
| 최소 점프 강도 | 0% | 0~100%, 1% 단위. 유효한 점프의 최소 발사 속도를 최대 속도의 비율로 지정 |
| 중력 | 30 | 5~60 월드 단위/초² |
| 좌우 최대 각도 | 65° | 0~85°. 수직을 기준으로 왼쪽·오른쪽 대칭 |

드래그를 게임 화면 높이 1080px 기준으로 환산합니다. 기본 감도에서 240px를 당기면 최대 속도입니다. 12px보다 짧게 움직이거나 위로 당기면 취소합니다. 각도 제한을 벗어나면 설정된 최대 각도로 발사됩니다. 새의 준비 자세는 힘과 관계없이 일정합니다.

오른쪽 점프 설정의 **최대 발사 속도 바로 아래**에 최소 점프 강도가 있습니다. 최소 30%라면 10% 강도로 당겨도 30%로 발사되고, 80%로 당기면 80%로 발사됩니다. 최대 속도가 18일 때 30%는 속도 5.4입니다. 100%로 설정하면 모든 유효한 점프가 최대 속도로 발사됩니다. 너무 짧거나 위로 당긴 입력은 최소 강도와 관계없이 취소합니다. 0%는 기존 동작이며, 예전 맵을 열 때도 0%로 시작합니다. 이 설정은 맵 저장·자동 복구·실행 취소에 포함되고, **점프 기본값 복원**을 누르면 0%가 됩니다.

## 개발자 모드로 점프 튜닝

편집 화면에서는 **오른쪽 설정 패널 맨 위의 노란색 개발자 모드 OFF · F3 버튼**을 누릅니다. 테스트 화면에서는 오른쪽 위에 있습니다. **F3**로도 켜고 끌 수 있습니다. 켜면 버튼이 민트색 ON으로 바뀌고, 앱을 새로 실행하면 OFF로 시작합니다. 모드를 끄면 일반 플레이의 작은 기준점과 선분으로 돌아옵니다. 개발자 모드의 수치와 발사 방향 표시는 숨겨집니다.

테스트 중 마우스를 누르고 당기면 클릭한 지점에 노란 십자가 생깁니다. 민트색 선은 클릭점에서 현재 마우스까지 당긴 방향·거리, 노란 화살표는 실제 발사 방향입니다. 점선은 수직 0°, 노란 호는 적용 각도입니다. 오른쪽 아래로 당기면 왼쪽 위로 발사되는 관계를 바로 확인할 수 있습니다.

- **각도:** 수직 기준으로 `왼쪽 21.3°`처럼 표시합니다. 입력 각도가 설정된 범위를 넘으면 입력 각도와 실제 적용 각도를 따로 보여줍니다.
- **강도:** `발사 속도 ÷ 최대 발사 속도 × 100`입니다. 높이나 에너지의 비율이 아닙니다. 입력 강도와 최소 강도를 적용한 실제 강도를 함께 표시합니다. 최소 강도로 올려 발사할 때는 **최소 강도 적용**이라고 표시합니다. 100%가 되면 더 당겨도 발사 속도는 커지지 않습니다.
- **거리:** 실제 화면에서 움직인 px와, 화면 높이 1080px로 환산한 기준 거리를 함께 보여줍니다.
- **취소되는 입력:** 짧은 당김과 위로 당기는 입력은 취소 이유와 강도 0%로 표시합니다. 표시 패널 위에서도 점프를 조작할 수 있습니다.
- **마지막 확정 점프:** 실제 발사된 각도·강도·속도·당김 거리와 당시 감도·최대 속도·최소 강도·중력·각도 범위를 유지합니다. 취소한 입력은 기록을 덮어쓰지 않습니다.

테스트에서 한 번 점프한 뒤 **Esc**로 편집에 돌아와 설정을 바꾸면, 마지막 점프 기록과 현재 설정을 비교할 수 있습니다. 개발자 모드와 점프 기록은 맵 JSON에 저장되지 않습니다.

실행 중인 기존 앱을 덮어쓰지 않고 새 빌드를 만들려면 Unity 메뉴 **Moonbird → Build Windows App To Developer Folder**를 사용합니다. 결과는 `Builds/Windows-Developer/MoonbirdStudio.exe`에 생성되며, 일반 Windows 빌드와 같은 기능을 포함합니다.

## 저장과 복구

**저장 / 다른 이름 저장**으로 JSON 맵 파일을 만들고 **열기**로 불러옵니다. JSON에는 발판, 시작점, 달, 낙하 한계와 점프 설정이 함께 들어 있습니다. 한글 파일명도 지원합니다.

`Maps/처음 달에 가는 날.json`은 Git 연동 시점의 자동 복구 맵을 일반 맵 파일로 내보낸 것입니다. 다른 PC에서는 앱의 **열기(Ctrl+O)**로 이 파일을 선택하면 됩니다. 여러 환경에서 이어서 작업할 맵은 프로젝트의 `Maps/` 폴더에 저장하고 커밋·푸시하세요. 자동 복구본은 PC별로 저장되므로 Git으로 함께 옮겨지지 않습니다.

편집 후 약 0.75초가 지나면 별도 복구본을 자동 저장합니다. 앱을 다시 열면 마지막 작업을 복구합니다. 복구본 위치는 `%USERPROFILE%/AppData/LocalLow/Moonbird/Moonbird Studio/Recovery/session.json`입니다. 자동 복구는 수동으로 저장한 JSON 파일을 덮어쓰지 않습니다.

맵을 새로 만들거나 다른 파일을 열거나 종료할 때 변경 사항이 남아 있으면 저장 여부를 묻습니다. 잘못된 JSON 파일을 열거나 파일 저장에 실패해도 현재 맵은 유지됩니다. JSON 형식 버전은 `formatVersion: 1`입니다.

## 검증과 개발

Unity Test Runner의 EditMode에서 `Moonbird.Tests`를 실행합니다. 점프 각도·힘·해상도 보정, 입력 취소, 맵 검증, 복제 분리, 히스토리, JSON 파일 왕복을 검사합니다.

개발 빌드의 자동 점검은 `MoonbirdStudio.exe -moonbirdSmoke "결과 폴더의 절대 경로"`로 실행합니다. 편집 작업, 실제 물리 점프·착지·추락, 원본 보존, 달 도착과 복구를 확인하고 `runtime-smoke.txt`, `editor.png`, `play.png`를 남긴 뒤 종료합니다. 이 모드의 자동 복구본은 지정한 결과 폴더 안에 따로 저장합니다.

Python이 있으면 프로젝트 루트에서 `python -X utf8 Tools/verify_windows.py`를 실행해 Windows 기본 파일 대화상자까지 포함한 전체 검사를 실행할 수 있습니다. 추가 Python 패키지는 필요하지 않습니다. 검사 중 열리는 파일 선택 창은 자동으로 처리됩니다.

별도 폴더 빌드는 `python -X utf8 Tools/verify_windows.py --exe Builds/Windows-Developer/MoonbirdStudio.exe --output TestResults/Windows-Developer`로 검사합니다. 일반 플레이의 선분 표시(`normal-drag.png`), 개발자 모드의 실시간 조준 화면, 확정 점프 기록, 편집 복귀 화면도 PNG로 남깁니다.

재미는 자동 검사로 판정하지 않습니다. 같은 코스를 반복하며 원하는 방향과 힘으로 점프할 수 있게 되는지, 실패 후 한 번 더 시도하고 싶은지를 먼저 확인해 보세요.

현재 MVP는 고정된 사각 발판과 마우스 조작에 집중합니다. 맵에 배치하는 발판의 회전·이동 동작, 모바일 조작, 별도 게임 배포 기능은 포함하지 않습니다.
